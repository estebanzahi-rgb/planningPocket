# Planning Poker

Aplicación web simple para sesiones de Planning Poker sin registro.

## Requisitos
- Node.js 18+
- npm

## Desarrollo local

### Frontend
```bash
npm install
npm run dev
```

### Backend
```bash
cd server
npm install
node index.js
```

## Despliegue gratuito recomendado
- Frontend: Vercel
- Backend: Render o Railway

## Variables de entorno
- `VITE_SOCKET_URL`: URL del backend para el frontend (por ejemplo, https://tu-backend.onrender.com)
