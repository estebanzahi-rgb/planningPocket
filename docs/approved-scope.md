# Alcance aprobado para el MVP

## Aprobado
- Aplicación web simple para Planning Poker.
- Sin registro ni correo electrónico.
- Creación de sesión anónima.
- Unirse a una sesión con un código.
- Ingreso de nombre de participante.
- Votación con valores 1, 3, 5, 8 y 13.
- Votación secreta hasta que el administrador la revele.
- Botón de revelar.
- Botón de resetear.
- Título editable de la historia.

## No aprobado para este MVP
- Autenticación con correo.
- Persistencia de sesiones entre reinicios del servidor.
- Historial de votaciones.
- Modo oscuro.
- Integración con bases de datos externas.
