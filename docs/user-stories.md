# Historias de usuario

## HU1 - Crear sesión
Como creador de sesión, quiero crear una nueva sesión de Planning Poker para iniciar una votación rápidamente.

## HU2 - Unirse a sesión
Como participante, quiero ingresar un código de sesión para unirme sin crear cuenta.

## HU3 - Registrar nombre
Como participante, quiero escribir mi nombre para identificarme en la sesión.

## HU4 - Votar
Como participante, quiero elegir un valor de votación para contribuir a la estimación.

## HU5 - Ver resultados
Como participante, quiero ver el resumen de votos para entender el consenso del equipo.

## HU6 - Reiniciar ronda
Como creador de sesión, quiero reiniciar la votación para preparar una nueva historia.
